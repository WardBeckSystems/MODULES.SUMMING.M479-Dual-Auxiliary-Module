## Summing cards

_WBS TECHNICAL SUPPORT · Apr 15, 2008|41_

> any line amplifier can be used as a summing amplifier. So if you want to use a neve summing buss, or api, you can.
>
> if you want to use all ward beck... you need to need
>
> M1-2 (2) M477 master buss modules.... or you can use any M497 Dual summing modules
> S1-S4 - are usually M473
> for the aux you could use either the M497 or the M479 dual aux module
>
> the solo buss would be fed directly into the M495 monitor input,
>
> I would suggest loosing the M495 as the monitor module... it doesnt truely solo, it actually just adds the solo to the master signal... the M475 actually mute when the solo is pushed (if you wire up the controle voltage right) the good thing about the 495 is that they are stereo and can run headphones
>
> I would suggest finding a schematic of a console and working with that as it's pretty much what you're doing

— **kuzub**, Apr 15, 2008|41
